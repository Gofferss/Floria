# Изображения главной страницы и шапки

Сохраните сюда файлы под точно такими именами — код уже на них ссылается.
Пока файла нет, соответствующее место на странице просто пустое (никаких
битых иконок) — можно добавлять по одному, сайт не сломается.

Букет на странице «О нас» — не файл, а SVG-иллюстрация прямо в коде
(`components/about/InteractiveBouquet.tsx`), загружать для неё ничего не нужно.

| Файл | Где используется | Требования |
|---|---|---|
| `logo.png` | Шапка сайта, слева | Логотип «Флория» (иконка + текст), квадратный/близкий к квадрату кадр. Фон — прозрачный (PNG с альфа-каналом), иначе в шапке будет виден белый/цветной прямоугольник вокруг лотоса. От 500×500px. |
| `hero-bouquet-summer.png` | Hero, справа от заголовка | **Летний букет, вырезанный на прозрачном фоне** (PNG с альфа-каналом, не JPG — у JPG нет прозрачности). Портретная или квадратная композиция, от 1000×1000px. Статичный, без анимации. |
| `flower-rose.png` | Hero, парит в левом верхнем углу | Одна роза крупным планом, вырезанная на прозрачном фоне. От 500×500px. |
| `flower-tulip.png` | Hero, парит в левом нижнем углу | Один тюльпан, вырезанный на прозрачном фоне. От 400×400px. |
| `flower-potted.png` | Hero, парит в правом верхнем углу | Цветок в горшке, вырезанный на прозрачном фоне. От 500×500px. |
| `pattern-left.png` | Hero, левый край (только экраны от 1280px) | Цветочный паттерн. **Может быть сплошным прямоугольником** (не обязательно прозрачным) — код сам делает его полупрозрачным и растушёвывает внутренний край в фон Hero через CSS-градиент. От 800×1200px, вертикальная композиция. |
| `pattern-right.png` | Hero, правый край (только экраны от 1280px) | Так же, как `pattern-left.png`. Можно использовать второй присланный вами паттерн (или тот же самый, отзеркаленный) — визуально не критично, какой из двух пойдёт налево, а какой направо. |

**Про "вырезано на прозрачном фоне":** если у вас есть обычное фото цветка
(с фоном — стол, стена, что угодно), это легко исправить бесплатно на сайте
[remove.bg](https://www.remove.bg/ru) — загружаете фото, скачиваете результат
уже с прозрачным фоном (PNG), кладёте сюда под нужным именем.

Все — рядом с этим файлом, прямо в `/public`, без вложенных папок:

```
public/
  logo.png
  hero-bouquet-summer.png
  flower-rose.png
  flower-tulip.png
  flower-potted.png
  pattern-left.png
  pattern-right.png
  category-tulips.jpg
  category-signature.jpg
  category-wedding.jpg
  category-subscription.jpg
```
