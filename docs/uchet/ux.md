# Флория Учёт — как этим пользоваться

Логика интерфейса: что на каком экране, сколько касаний до результата,
что делается не уходя со страницы. Пишется **до кода** и обновляется,
когда флористы скажут, что неудобно.

---

## 0. Отдельное приложение

Учёт живёт по адресу **`/uchet`** и выглядит как отдельная программа:
без шапки магазина, подвала, корзины и меню сайта. На iPad ставится на
экран «Домой» и открывается во весь экран, как приложение.

Почему не внутри админки сайта: у них разные люди и разный темп.
Админка сайта — это витрина для покупателей (статьи, сторис,
промокоды). Учёт — рабочее место флориста, которое открыто весь день и
где важна скорость. Смешивать их — значит, что флорист видит лишнее, а
владелец ищет нужное.

Связь остаётся главной: та же база, тот же каталог, те же заказы.
Заказ с сайта сразу появляется в учёте, букет с витрины сразу виден на
сайте.

## 1. Кто и с чего заходит

| Кто | Устройство | Что видит |
|---|---|---|
| Флорист | iPad в магазине, горизонтально | Касса, Заказы, Витрина, Склад (без себестоимости), Смена |
| Владелец | ноутбук, телефон | Всё, плюс Сводка, деньги, сотрудники, отчёты, себестоимость |
| Курьер | телефон | Только свои доставки |

**Планшет входит один раз, люди — по PIN.** iPad магазина залогинен
служебной учётной записью с правами флориста. Каждый, кто работает,
выбирает себя и вводит 4 цифры — дальше каждое действие подписано им.
Смена флористов — два касания, без SMS. Владелец на своём устройстве
входит своей учётной записью и видит владельческий интерфейс.

## 2. Каркас экрана

```
┌──────┬──────────────────────────────────────────────────────┐
│ ЛЕВЫЙ│  ВЕРХНЯЯ СТРОКА: раздел · Катя · смена 09:12 · 12 400 ₽ │
│ РЕЛЬС│                               в кассе · ● всё отправлено │
│      ├──────────────────────────────────────────────────────┤
│Касса │                                                      │
│Заказы│                  РАБОЧАЯ ОБЛАСТЬ                      │
│Витрин│                                                      │
│Склад │                                                      │
│Смена │                                                      │
│ ···  │                                                      │
└──────┴──────────────────────────────────────────────────────┘
```

- **Левый рельс всегда виден** (а не прячется за «гамбургер», как у
  Posiflora): раздел переключается одним касанием. Иконка + подпись.
- **Верхняя строка** — то, что флорист должен видеть всегда: кто
  работает (касание — сменить сотрудника по PIN), открыта ли смена,
  сколько наличных должно быть в кассе, отправлено ли всё на сервер.
- **Цвет — только там, где нужно внимание** (решение владельца
  22.10.2026, вместо цветных групп): красная полоска — нет или в минусе,
  жёлтая — мало, жёлтая метка «5 дн.» — лежит дольше срока свежести.
  Остальное белое и спокойное, поэтому важное видно сразу.
- **Группы — со значком**: роза, кустовая роза, хризантема, игрушки,
  шары, открытки (`components/uchet/GroupIcon.tsx`). Значок выбирает
  владелец в справочнике групп. У Posiflora цвета папок случайные, и
  «ИМПОРТ» чёрным рядом с «Уценкой» жёлтым читать трудно.

## 3. Касса — главный экран

Две колонки, как у Posiflora, но с другим смыслом колонок.

```
┌───────────────────────────────────┬─────────────────────────┐
│ [поиск: название, штрихкод     ]  │ ПРОДАЖА  ○ сейчас ● на дату│
│                                   │ + Клиент                │
│ [Витрина 11] [Букет по цене]      │                         │
│                                   │ ▾ Букет 1         2 500 ₽│
│ ★ Частые                          │   хризантема бигуди × 5 │
│ [Хриз.бигуди][Эвкалипт][Роза Мисс]│   эвкалипт × 3          │
│                                   │   крафт × 1             │
│ Группы                            │ + Новый букет           │
│ [Цветы][Роза][Кустовая][Хризант.] │                         │
│ [Зелень][Упаковка][Игрушки][Шары] │ Открытка            150 ₽│
│                                   │─────────────────────────│
│                                   │ Скидка · Бонусы         │
│                                   │ К ОПЛАТЕ        2 650 ₽ │
│                                   │ [ Отложить ] [ ОПЛАТА ] │
└───────────────────────────────────┴─────────────────────────┘
```

### Что изменено против Posiflora

| У Posiflora | У нас | Почему |
|---|---|---|
| Кнопка «Букет» — маленький кружок внизу справа | «+ Новый букет» — в самом чеке, на виду | Это главное действие флориста |
| Букет называется «Букет 45124525» и стоит 0 ₽, пока не наберёшь состав | «Букет 1», цена видна сразу: по составу или вручную | Число без смысла и ноль в чеке пугают |
| Витрина — кнопка рядом с «Букетом» | Плитка «Витрина» с числом букетов — первой в ассортименте | Продажа готового — самая частая |
| Позиции «БУКЕТ 2000» в категории «Букет до» | Кнопка «Букет по цене»: ввёл 2 500 — букет в чеке | То же самое, но без 24 фиктивных позиций |
| Всё — «заказ» | Переключатель «сейчас / на дату» | Продажа в зале не должна требовать даты и клиента |

### Сценарии и касания

1. **Готовый букет с витрины** — Витрина → букет → Оплата → способ →
   готово. **4 касания.** Букет снимается с витрины и с сайта сам.
2. **Букет по цене** — «Букет по цене» → набрать 2 500 на цифровой
   клавиатуре → Оплата → способ. **4 касания + цифры.** Состав можно
   добавить, а можно нет — но тогда цветы не спишутся со склада, и
   букет помечается «без состава». Вечером бот напомнит: «3 букета
   продано без состава». Владелец может включить настройку «состав
   обязателен».
3. **Собрать на месте** — «+ Новый букет» → касания по плиткам цветов
   (каждое касание = +1 стебель; долгое касание = ввести количество) →
   цена предлагается сама → Оплата. Изменить цену — касание по цене.
4. **Мелочь** — игрушка, шар, открытка: касание по плитке. Добавляется
   отдельной строкой, не в букет.
5. **Заказ на дату** — переключатель «на дату» → открывается панель:
   дата и время, доставка / самовывоз, адрес, получатель, открытка,
   предоплата. Состав можно оставить «в бюджет N ₽ на усмотрение
   флориста» и собрать позже.
6. **Клиент** — «+ Клиент» → телефон → найден (видны бонусы, прошлые
   заказы, «повторить») или новый. Необязательно. Бонусы 5% начисляются
   сами.

### Мелочи кассы

- **Цена букета** предлагается по составу. Как считать — настройка
  владельца: сумма розничных цен стеблей, или себестоимость × наценка.
  Флорист видит только итог, не себестоимость.
- **Плитка позиции**: название, цена за штуку, остаток. Мало — жёлтая
  метка, нет или минус — красная, но продать можно (продажу не
  блокируем ради цифры). У цветов точка свежести: зелёная — свежие,
  жёлтая — пора в работу.
- **Частые** — компактной строкой «название · цена», 12 позиций, которые
  чаще всего продавались за 30 дней; пока своих продаж мало, список
  дополняется самыми ходовыми по Posiflora. Остаток в строке — только если
  с ним что-то не так. Плюс (позже) флорист может закрепить свои.
- **Строку в чеке** убирают смахиванием или кнопкой; 5 секунд висит
  «Отменить». Подтверждений нет — всё обратимо до оплаты.
- **Скидка** — в процентах или рублях. До лимита (настройка, например
  10%) — сам флорист, больше — PIN администратора. Каждая скидка видна
  владельцу.
- **Отложить чек** — позвонили посреди продажи. Отложенные — списком над
  чеком, касание возвращает.
- **Чек не теряется**: всё набранное сохраняется на планшете, даже если
  приложение закрыли или пропала сеть.

### Оплата

Панель снизу на полэкрана, крупно:

- Способы (настраиваются): наличные, карта (терминал), СБП, перевод,
  бонусы. **Смешанная** — несколько способов с суммами.
- Наличные: «дали 3 000» → «сдача 350» крупно.
- Заказ на дату: можно взять предоплату, остаток виден в заказе.
- После оплаты — «Готово» и две кнопки: «Новая продажа» и, если у
  клиента есть бот, «Отправить фото».
- Чек (фискальный) пробивается отдельной кассой, как сейчас. Здесь —
  только учёт.

## 4. Заказы

Колонки «Сегодня / Завтра / Позже», внутри — по времени. Заказы с сайта
здесь же.

Карточка: время, доставка или самовывоз, адрес коротко, получатель,
состав в одну строку, **оплачено / нет** (крупно — чтобы не взять деньги
дважды), статус, флорист.

**Касание по карточке открывает панель справа, не уходя со списка**: всё
о заказе и кнопки статусов. Статусы:
Новый → В работе → Собран (фото → клиенту) → У курьера → Доставлен /
Выдан. Отменён — отдельно, с причиной.

Мелочи: «Собран» без фото не ставится (фото — одним касанием камеры, их
может быть несколько); у заказа на ближайшие 2 часа, который ещё не
собран, — красная полоса; фильтр «мои».

## 5. Витрина

Плитки с фото, цена, сколько дней стоит (1 — без метки, 2 — жёлтая, 3+ —
красная), значок «на сайте», «забронирован с сайта».

Действия из плитки, не открывая букет: Продать (в кассу), Изменить цену,
Показать на сайте / убрать, Разобрать (цветы обратно на склад), Списать
(завял).

**Собрать на витрину** — как букет в кассе, но вместо оплаты кнопка «На
витрину»: фото → цена → готово. Цветы списываются со склада сборкой, на
витрине появляется букет. При продаже со склада уже ничего не
списывается — всё списалось при сборке.

## 6. Склад

### Список

- Сверху — плитки групп цветом вида, с количеством позиций и
  предупреждений (минус, мало, залежалось). Касание — фильтр по группе.
- Под ними — готовые фильтры-чипы: «есть в наличии», «мало», «в минусе»,
  «залежалось», «скрытые».
- Таблица сортируется касанием по любой колонке; выбранная сортировка
  запоминается.
- **Касание по строке открывает панель справа, а не новую страницу.** В
  панели: остаток, свежесть, последние движения и быстрые действия —
  **Приход**, **Списать**, **Пересчитать**, **Цена**, **Минимум**,
  **Скрыть**. Каждое — маленькая форма прямо в панели. Пример: «Списать»
  → количество → причина кнопкой → готово. Внутри это обычный документ
  из одной строки, проведённый сразу, — журнал остаётся честным.
- **Отметить несколько** (владелец): галочки в строках → внизу
  появляется полоса действий: «Сменить группу», «Скрыть», «Пересчитать
  выбранные» (открывает инвентаризацию с этими позициями), «Списать
  выбранные».
- Себестоимость, средняя и стоимость остатка — только у владельца.

### Документы

Те же приход, списание, инвентаризация, что сейчас, но в приложении.
Для пачки товара (привезли 15 позиций) — полный документ; для одной
позиции — быстрое действие из панели.

### Закупка из кассы

Сейчас цветы покупают «изъятием» с причиной «Эустома». У нас при
изъятии из кассы есть причина «Закупка» — она открывает приход с
оплатой «из кассы». Одно действие — и деньги ушли, и цветы пришли.

## 7. Смена

- **Открыть**: пересчитать наличные (цифровая клавиатура), если не
  сходится с закрытием прошлой — показать разницу.
- **Внести / изъять**: сумма + причина кнопкой (закупка, зарплата,
  инкассация, хозяйственное, другое). Зарплата — с выбором сотрудника.
- **Закрыть**: пересчитать наличные → ожидалось / фактически /
  расхождение → итоги смены (по способам оплаты, списания) → владельцу
  в бот.
- Без открытой смены касса предлагает открыть её одним шагом, а не
  ругается.

## 8. Владельцу

- **Сводка**: сегодня, неделя, месяц — выручка, заказы, средний чек,
  наличные, списания. Ниже — что требует внимания: минусы, залежавшиеся
  букеты, незакрытая смена, неотправленные операции, скидки сверх лимита.
- **Сотрудники**: люди, PIN, роль, схема оплаты из кирпичиков (оклад,
  смена, процент от личных продаж / от продаж в смену / от всей выручки,
  за букет). Начисления за период считаются сами.
- **Деньги**: смены с расхождениями, движения кассы, расходы по статьям.
- **Отчёты**: прибыль и убытки, маржа, списания по позициям и
  поставщикам, продажи по меткам, часам и дням недели, праздники год к
  году.

## 9. Общие правила для всех экранов

1. **Панель справа вместо новой страницы.** Посмотреть и сделать мелкое
   действие — не уходя со списка. Новая страница — только для большого
   документа.
2. **Подтверждение — только для необратимого**: проведение, оплата,
   сторно. Остальное — с «Отменить» на 5 секунд.
3. **Касание ≥ 44 точек**, цифры — на своей цифровой клавиатуре, а не на
   системной, которая закрывает пол-экрана.
4. **Числа — моноширинным, выровнены вправо**, минус — красным.
5. **Ошибка говорит, что делать**: «Строка 2: укажите цену закупки», а
   не «ошибка 422».
6. **Состояние сети видно всегда.** Без сети работает касса, заказы на
   планшете, витрина, склад; не работают ссылки на онлайн-оплату и
   отправка в Telegram — они ждут в очереди.
7. **Ничего не удаляется насовсем**, кроме черновиков. Ненужное
   выключается и остаётся в истории.
